How To Play

  • Driver's License mode: Location, sex, height, hair & eye color, date of birth. Type the historical figure's name.
  • License Plate mode: A location and a coded plate combo hinting at a historical event. Type the event.
  • Case File mode: A full detective's dossier on the same cast of historical figures — occupation, era, alias, associates, distinguishing marks, and more. Same objective: name the figure, using far more clues.
  • Each mode has 50 levels laid out in a grid — beat one to unlock the next, tracked separately per mode.
  • Harder levels redact more fields — use a hint to reveal one, at the cost of some points.
  • You've got 3 lives per level attempt. Run out and you'll need to retry that level.
  • Close spellings, last names, and common nicknames are all accepted.
